# Cardappy Print

Instalador do Cardappy Print, a estação de impressão do Cardappy para Windows.

**Baixar:** https://github.com/ahmedhijazi94/cardappy-print-releases/releases/latest/download/Cardappy-Print-Setup.exe

Depois de instalar, conecte o computador à loja em Configurações → Impressoras, no painel do Cardappy.

Este repositório guarda só os instaladores. O código fica em outro lugar.
